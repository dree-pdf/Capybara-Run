# Capivara Run 🐾

Um jogo eletrônico de corrida infinita (endless runner) para navegador, inspirado no clássico jogo do dinossauro do Google Chrome, ambientado no bioma do Pantanal brasileiro.

# Objetivo do Jogo

Ajudar a capivara a atravessar a planície pantaneira o mais longe possível, desviando de obstáculos terrestres (troncos e jacarés) e aéreos (tuiuiús/aves).

# Regras

Pontuação: A pontuação aumenta progressivamente com base na distância percorrida em metros.

Velocidade: Conforme a pontuação avança, o jogo acelera gradualmente.

Colisão: Encostar em qualquer obstáculo encerra a partida instantaneamente.

Recorde: O maior recorde fica gravado no navegador via localStorage.

# Controles

Barra de Espaço ou Seta para Cima (↑): Salto.

Seta para Baixo (↓): Agachar (desvia de aves) ou queda rápida caso pressionado em pleno voo.

Telas sensíveis ao toque (Dispositivos Móveis): Toque no canvas ou utilize os botões virtuais dedicados na parte inferior da tela.

# Tecnologias Utilizadas

HTML5: Estruturação semântica e elemento <canvas>.

CSS3: Estilização moderna, responsividade e layout flexível.

JavaScript (Vanilla puro): Lógica do jogo, física vetorial, detecção de colisões AABB e sintetizador sonoro com Web Audio API.
